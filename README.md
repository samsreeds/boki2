# 簿記二級 稽古帳

日商簿記2級（商業簿記・工業簿記）の学習教材です。アニメーションの図解で論点の仕組みを学び、仕訳と計算の入力式テストで理解を確かめます。

**商業簿記**：売上原価対立法・棚卸減耗・収益認識／有価証券（償却原価法・端数利息）／減価償却3方式・圧縮記帳・リース／外貨建取引・税効果会計・引当金／配当と準備金・本支店会計／連結会計（投資と資本の相殺消去、のれん、非支配株主持分）

**工業簿記**：原価の流れ（勘定連絡）／先入先出法・移動平均法、予定価格と差異／製造間接費の差異分析（シュラッター図）・部門別計算／個別原価計算・総合原価計算（ボックス図）／標準原価計算の差異分析／CVP分析・直接原価計算

**テスト**：仕訳59問・計算21問（正解状況はブラウザに保存）

2026年度試験の出題範囲に合わせています。`index.html` 1ファイルで動き、ビルドは不要です。3級版は [boki3](https://samsreeds.github.io/boki3/) にあります。
